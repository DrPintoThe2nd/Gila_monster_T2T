# Gila_monster_T2T
Analysis code for the Gila monster T2T genome project

Here we present the first telomere-to-telomere reference genome for a squamate reptile, Heloderma suspectum, the Gila monster. The Gila monster is a large, venomous lizard native to the deserts and scrublands of the southwestern United States and northwestern Mexico. It is one of a few beaded lizard species in North America. It is recognized by its distinctive black and orange or pink bead-like scales and slow-moving behavior. Unlike most lizards, the Gila monster stores fat in its tail, feeds on eggs, small mammals, birds, and reptiles, and uses its venomous bite primarily for defense rather than predation. Although it is venomous, encounters with humans are uncommon, and bites are rarely life-threatening when treated appropriately.

This repository contains code for: 
1. Generation of the Gila monster reference genome
2. Sex chromosome dosage investigations
3. Gametolog analysis
4. Salivary-focused study
5. Analysis of telomeric repeats
